# Specifications

Specification documents for this project live here — the written specs the
work is held to once they are settled: a study-design or analysis
specification, a pre-registration, a protocol spec, a data or figure contract
written up in full, or any document that pins down *what must be true* rather
than narrating how the work is going.

This is **not** `plan/README.md`. That file is the living project document — it
changes as the work does. A specification is a fixed contract: it is written
when a decision is nailed down, dated, and then referenced rather than
rewritten. When a spec is produced, it goes here, one document per file, named
for what it specifies (`analysis_spec.md`, `preregistration.md`,
`data_contract_spec.md`).

Nothing is generated into this folder on day one — a file here means a spec was
actually written. The folder ships with this README alone so there is always a
home for the first one.

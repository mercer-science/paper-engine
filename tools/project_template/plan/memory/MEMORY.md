# Project memory

Decisions that would otherwise be re-litigated, and the reasoning behind them.
One entry per decision, newest at the top, dated. This is not a log of what
happened — it is what a future session needs to know to not undo a choice.

Working notes and open questions belong in `plan/README.md`; they graduate to
here once they are settled.
